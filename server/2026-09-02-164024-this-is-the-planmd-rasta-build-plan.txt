  Two consequences that shape the code from day one:                            
                                                                                
  **Edge TTS wants Urdu script, not Roman.** Feeding `ur-PK-AsadNeural` Roman   
  Urdu produces mush. So every instruction template carries two strings from    
  the                                                                           
  moment it's written — `latin` and `native` — and the speech layer picks based 
  on which engine is live. Ten extra string literals in one file, versus        
  rewriting the template layer mid-week.                                        
                                                                                
  **Groq Whisper deletes the day-7 Android risk rather than working around      
  it.**                                                                         
  Android WebView has no Web Speech recognition, which is the single thing most 
  likely to eat day 7. Recording a blob and POSTing it to Groq works            
  identically                                                                   
  in Chrome and in a WebView. That's why the STT swap is scheduled for day 5,   
  not                                                                           
  treated as a stretch goal — it buys down risk two days before the risk lands. 
                                                                                
  **Edge TTS needs no key.** It's an unofficial endpoint. The only key in this  
  project is Groq's. See §4.4 for how it's handled.                             
                                                                                
  ---                                                                           
                                                                                
  ## 1. Guiding constraints                                                     
                                                                                
  - **The free path always works.** Groq and Edge TTS are upgrades layered onto 
    a system that already navigates end to end with browser-native APIs. If a   
    key expires or an endpoint moves, the app degrades a notch and keeps        
    talking. It never dead-ends. §2.7 specifies exactly how.                    
  - **One innovation, done properly.** The landmark saliency ranker is the      
    thesis. It is pure, testable, offline logic with no API call. Everything    
    else is plumbing around it, and should look like plumbing.                  
  - **Every external boundary is swappable in one file.** Not through an        
    abstraction layer — through a function signature and a lookup object. §3.   
  - **Demo-scoped.** One city corridor, public endpoints, no backend, no        
    database, no accounts.
